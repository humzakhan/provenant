# Fauxbooks End-User Scenario E2E

This planning folder defines the next e2e harness slice: realistic finance-user questions over Fauxbooks-generated `monthly-close` files with Provenant grounding.

Files:

- `plan.md`: implementation plan, scenario definitions, dataset commands, verifier rules.
- `goal-runner.md`: one-command runner contract and acceptance criteria.
- `golden-report.md`: target shape for the final markdown findings report.

Required scenarios:

1. Quarterly revenue summary.
2. Cash vs book revenue reconciliation.
3. Accounts receivable aging.
