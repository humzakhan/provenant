## CLI Commands

All commands are registered in `access/cli` and are <StatusBadge status="Implemented now" />.

| Command | What it does |
|---|---|
| `read-mint-bundle` | Read one JSON source → mint one token → emit bundle. |
| `reconcile` | Deterministic CSV/XLSX reconciliation fixture → ZIP report. |
| `run start` | Open a new runfile. |
| `run finish` | Mark a runfile as finished. |
| `run fail` | Mark a runfile as failed. |
| `read-mint` | Read a source and mint into a runfile. |
| `calc` | Derive a token via a calc op and inputs. |
| `submit-answer` | Record a labeled answer in the audit trail. |
| `verify` | Check bundle integrity and hash chain. |
| `replay` | Verify and reconstruct in-memory state. |
| `pack` | Build a JCS-canonical audit pack from a bundle and sidecars. |
| `trace` | Walk a token's lineage to leaf sources. |
| `audit-html` | Render an audit pack as a self-contained HTML report. |

The quickstart features `read-mint-bundle`, `reconcile`, `verify`, and `replay`. All commands are present in code and listed here as their public reference.

## Go Public Packages

All packages are under `github.com/provenant/provenant/…` and are <StatusBadge status="Implemented now" />. See [Integrate the Go Library](/guides/integrate-go-library/) for usage details.

| Package | Contents |
|---|---|
| `kernel/public` | Core types `Run`, `Token`, `CapturedRead`, `AuditEntry`; entry points `ReadAndMint`, `MintFromCapturedRead`; injected interfaces `Store`, `AuditSink`, `TransactionalScope`, `SourceResolver`, `SourceReader`, `Clock`. |
| `kernel/public/bundle` | `Verify`, `Replay`, `Emit`, type `State` — offline bundle operations, no network required. |
| `kernel/public/derive` | `Derive` — compose tokens through filter and calculation operations. |
| `kernel/public/memio` | `NewBinding` — in-memory binding, the library-mode default. |
| `kernel/public/trace` | `Trace` — walk a token's derivation lineage to leaf sources. |
