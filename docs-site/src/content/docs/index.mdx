<div class="hero-panel">
Provenant is a Go provenance enforcement layer for regulated finance workflows. It records where output numbers came from, mints tokens from captured reads, writes a hash-chained audit trail, and emits audit bundle bytes that can be verified and replayed.
</div>

Provenant is not a SaaS product, database, agent, model, logger, reconciliation product, or generic guardrail. The library is the core product. CLI, MCP, and HTTP are access surfaces around the same kernel, and current public examples are intentionally small.

## Current Mental Model

```text
source bytes -> SourceReader.Read -> CapturedRead + ReadResult
                                   -> kernel.MintToken
                                   -> hash-chained audit entry
                                   -> bundle.Snapshot
                                   -> bundle.Verify / bundle.Replay
```

## Glossary

- `CapturedRead`: stable record of a source read, including source path, reader, selector, and output hash.
- `Token`: kernel-issued provenance value bound to a captured read or derivation.
- `Audit entry`: one hash-chained JSONL record in a run.
- `Audit bundle`: canonical bytes containing the run, captured reads, tokens, and audit JSONL.
- `Replay`: offline re-derivation from captured bundle bytes, not a fresh external-source run.
- `submit_answer`: the guarded release path for regulated conclusions.
- `Mode A`: Provenant-owned or embedded harness path.
- `Mode B`: host-driven adapter path, such as MCP, where host-channel text is not automatically attested.

<CaveatCallout title="Mode B attestation limit" tone="warn">
  Marker verification is necessary for a regulated conclusion, but v0 host conformance is self-declared. Untested hosts can complete as `host_text_only`; use Mode A when unsigned host text is unacceptable.
</CaveatCallout>

<CaveatCallout title="Audit evidence language" tone="warn">
  v0 audit evidence is internally tamper-evident through hash-chain verification. These docs do not claim tamper-proof, externally notarized, or legal-advice status.
</CaveatCallout>
