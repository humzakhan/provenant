# Codex / Pi architecture review lineage

These files are archived research and review artifacts from the Codex/Pi subagent workflow used for the architecture review.
They are preserved for lineage only, not as source-of-truth architecture documentation.

## Artifacts
- `boot-context.md` — boot/context scope and routing rules gathered for the review run.
- `thesis-context.md` — thesis mission, invariants, and alignment criteria.
- `architecture-context.md` — architecture brief, assumptions, and phase boundaries.
- `plans-context.md` — implementation-plan context used for thesis alignment.
- `oracle-solutions.md` — oracle patch plan / solution recommendations.
- `report-review.md` — review of the draft architecture report.
- `review-thesis-alignment.md` — thesis alignment review notes.
- `review-sweeper-persistence.md` — sweeper / persistence review notes.
- `docs-patch-worker-handoff.md` — worker handoff for the docs patch pass.
- `report-writer-handoff.md` — handoff used when drafting the report.
- `final-blocker-fix-handoff.md` — handoff for final blocker fixes.
- `final-docs-review.md` — final documentation review notes.
- `final-ready-review.md` — final readiness review notes.
